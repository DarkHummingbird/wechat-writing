# 公众号写作 Skill

面向 AI、科技与 AI 产品的中文公众号写作搭档。

调用 `$wechat-writing` 并提供一句观点、标题、热点或链接，即可开始：简短澄清 → 标题与切入角度 → 大纲选择 → 确认后成稿。已有稿件可直接编辑，用户可明确跳过阶段。

- 完整正文默认 5000 字以上，以事实和具体过程支撑表达。
- 热点候选中包含 AI 产品经理视角，其他角度保持差异。
- 写法库可扩展，按材料选择或组合，不固定文章模板。
- 主动寻找公告、X 原帖和产品资料等真实配图；获取不到时在正文留说明和原始链接，方便自行补图。
- 配图与全文氛围一致，不默认培训课件风格。

将完整目录放入环境支持的 Skill 发现目录，保留 `SKILL.md` 和 `references/`。也可使用 Codex 的 skill-installer 从本仓库安装。本 Skill 不依赖 WeWrite，不会代替用户发布文章。

规则入口：[SKILL.md](SKILL.md)；可选写法：[references/index.md](references/index.md)。
