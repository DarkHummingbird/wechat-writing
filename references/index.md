# 可扩展写法库

这是参考索引，不是必须从中选一个的分类表。未来增加参考时补充条目，不要求重写主流程。

| 参考 | 素材适用条件 | 阅读时机 |
| --- | --- | --- |
| [制作过程复盘](process.md) | 有成品、旧做法、过程与关键决策 | 项目幕后、实践复盘、工具流程 |
| [从细节展开的个人叙事](personal.md) | 有真实场景、经历、矛盾与选择 | 个人成长、习惯、职业变化 |
| [经验与方法](method.md) | 有具体问题、案例及可操作步骤 | 工作方法、实践分享 |
| [科技新品报道与行业评论](tech-news.md) | 有新品或功能发布，以及可核实的使用条件；行业比较需要另有材料 | 科技新闻、产品发布、赛道观察 |
| [事件推进与读者代入](event-narrative.md) | 有可追溯的行动、转折与后果，可联系读者处境 | 事件叙事、变化评论、实践故事 |
| [从现实后果追到原因的事件解释](event-explainer.md) | 有具体影响、多方过程或需要解释的成果声明 | 科技事件、基础设施影响、研究解读 |

新闻评论可以借鉴场景与矛盾的展开，不需要假装成亲身经历。新闻解释可以借鉴案例到机制的推进，不需要冠以“方法论”。

配图时按需读 [配图与提示词](images.md)：包含真实素材主动搜集与核验、图文推进、插画提示词及图表制作指令，不限定文章写法或视觉风格。
