# 制作过程复盘

来源：[我是怎么被写出来的](https://sspai.com/post/107114)。这是结构分析，不是原文事实背书。

值得借鉴：将成品与制作过程联系，展示旧流程的问题、改变的原因和关键修改，让读者看到选择如何形成。原文让文章自己讲述诞生，是可选的特殊视角；其章节体、流程图和提示词引用用于说明流程。

可用骨架：成品引出问题 → 旧做法及卡点 → 新理解或新做法 → 本次关键过程 → 回看结果。只保留实际存在的环节；短复盘无须铺满背景。

需要材料：过程记录、版本差异、取舍与结果。没有记录不编造迭代次数、耗时或否决反馈。原文的总耗时与末尾时间轴不一致，借鉴时尤其核对数据。特殊叙述视角若无法持续或妨碍准确，使用普通叙述。
